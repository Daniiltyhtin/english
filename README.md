# Словари терминов к статьям

Страница для повторения терминов научных статей: список с отметками «выучил» и «в повторение», самопроверка, флеш-карточки, озвучка.

Сайт: https://daniiltyhtin.github.io/english/

## Как добавить статью

1. Положить словарь в `data/<тема-статьи>.md`. Формат: заголовок `# … «Название статьи»`, разделы `## N. Название`, под каждым таблица `| Термин (EN) | Транскрипция | Перевод (RU) |`.
2. Добавить строку в `data/articles.json`: `{ "id": "<тема-статьи>", "file": "data/<тема-статьи>.md" }`. Необязательное поле `"look": "inferno"` включает для статьи «адское» оформление: оно включается при каждом выборе статьи, светлый или тёмный вариант следует переключателю темы, а кнопка «🔥 Оформление» его отключает.
